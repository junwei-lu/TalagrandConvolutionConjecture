# TalagrandConvConjecture

Lean 4 formalization of Talagrand's convolution conjecture on the Boolean
hypercube, following Lu–Guo–Fang, *Weak-Type Bounds for Convolution on the
Boolean Hypercube* (with inputs from Chen 2026 and Xiang–Zhang 2026).

Headline: `Talagrand.talagrand_convolution_conjecture` in
`TalagrandConvConjecture/Statement.lean`.

Independent Lake project; Mathlib pinned at `v4.29.1`, StatLean required from
GitHub (`StatLean/Stat-Lean`). Builds run on the FAS-RC cluster.
